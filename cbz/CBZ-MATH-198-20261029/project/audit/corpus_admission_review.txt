FINDING 1 -- IMPORTANT, FIXED: MALFORMED OPTIONAL RECEIPT BOOLEANS ADMIT

The initial receipt guards use source_exposed is not True and
training_eligible/discovery_eligible is not False. In disposable synthetic
fixtures, repinning the changed receipt and separately pinned operator policy
still yields policy_admitted_fixture with each of:
  source_exposed = 1
  source_exposed = "true"
  training_eligible = 0
  training_eligible = null
  discovery_eligible = 0
The saved-document trust model does not excuse accepting invalid representations
of defined policy fields. Validate their type when present, then apply the
exposure/ineligibility gate. This does not forge a kernel receipt or turn any
scientific/training flag true; it violates the default-deny schema boundary.
Omission compatibility can remain explicit because independent provenance and
attestation documents already require literal source_exposed:false.

The fix recursively validates all recognized present Boolean metadata as exact
bool in parsed documents and canonicalized identities, before semantic guards.
Optional omission retains the explicit compatibility above. Invalid present
0/1/0.0/1.0/null/string/list/object values now deny; literal booleans retain their
correct exposure/eligibility semantics. This also protects other recognized
Boolean metadata from Python's False==0/True==1 aliases.

FINDING 2 -- MALFORMED-INPUT ROBUSTNESS, FIXED

A dataset containing a 5000-digit JSON integer, well below the 8MiB limit,
raises uncaught ValueError from Python's integer conversion limit rather than
returning a denied report. A record family containing escaped lone surrogate
U+D800 raises uncaught UnicodeEncodeError during canonical identity encoding.
Both cause CLI traceback/absent JSON instead of a structured refusal; neither
produces an eligible result. An otherwise unused dataset field 1e10000 becomes
Python inf and admits: parse_constant rejects literal NaN/Infinity but does not
check exponent overflow. These observations were sent with the schema finding.

The fix bounds integer tokens to 4300 digits, rejects nonfinite float conversion,
recursively validates UTF-8 scalar/key encoding and finite numeric values, uses
allow_nan=False in canonical JSON, and converts ValueError/UnicodeError into
typed denial. Embedded-NUL artifact paths reject before filesystem operations.
Fresh regression controls reproduce each original issue and now pass.

references bind the exact artifact, target, source, proof, runtime and baseline
to saved receipt, provenance and review bytes. A proposal's claimed_eligible
field grants no authority. Replacing the policy and supplying its new expected
hash is an external operator trust decision. The tool does not authenticate
reviewer honesty or establish a historical non-exposure fact from self-asserted
documents. README/docstrings/notes describe that limit explicitly.

family map and cross-split checks enforce disclosed family separation. They
cannot discover dishonest family relabeling or undisclosed previous campaigns.
