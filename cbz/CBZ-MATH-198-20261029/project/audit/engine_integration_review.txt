FINDING 1 -- IMPORTANT, FIXED: typed catalog metadata substitutions

Original verify_catalog/verify_certificate used Python dict equality. Disposable
mutations endpoints[0].training_eligible=0, source_exposed=1, or
proof_source_line=175.0 all passed catalog verification AND coherently exported
certificate verification because Python equates False==0, True==1, 175==175.0.
This did not forge a theorem or turn false eligibility true; it did violate the
advertised exact typed metadata boundary and the explicit boolean fields.
The fix introduces canonical_json(...,allow_nan=False), compares canonical JSON
bytes in both verification functions (catalog.py:161/177), and uses that same
canonical encoding for the export catalog digest. All three substitutions now
reject independently. Export-only substitutions and coherently changed exports
are covered by the added regression. Author RED/GREEN traces are retained in
evidence/catalog_types_red.txt and catalog_types_green.txt.
