## What the note states (paraphrase; the note governs)

Here `D := (1/2400)∫_0^∞ k^{−8/3}e^{−12k²}E[γ⁶(I − I_quad)(t, χ₀)] dk` with `I(t, χ₀) = Φ(1 − t, 8 − 12t + χ₀)`, `t = 12kB/γ²`, `χ₀ = 576k²C₃/γ³`, `(γ, B, C₃) ~ N(0,2) ⊗ N(0,2) ⊗ N(0,6)`, `I_quad` the quadratic polynomial of note DC, and `Φ` the closed form of #244 (2.5)–(2.7).

- **Reduction (§1).** `D = ∫du∫dω ρH` over `τ = e^u`, `g = e^ω`, with `ρ = c₀τ^{−5/3}g^{11/3}e^{−12τ²g⁴ − g²/4}`, `c₀ = 1/(2400√π)`, and `H = E[g(σ_tZ₁, σ_χZ₂)]`, `σ_t = 12√2τ`, `σ_χ = 576√6τ²g`, where `g = I − I_quad`; the `v`-form of `Φ` ((1.1), from #244 (2.5)–(2.7)); and the `(t, v)` form `H = (24τ√π)^{−1}∫F dv` with closed-form `t`-moments (1.3).
- **Lemma 1.** A pointwise bound `|g| ≤ g̃(t, χ)` by an explicit polynomial in `|t|`, `|χ|`, `|c′|` and `ρ_R = (R²/16)^{1/3}`.
- **Lemma 2.** The `(u, ω)`-derivatives of `H` fall on the Gaussian kernels: `∂_u^a∂_ω^bH = E[gQ_{a,b}]` with explicit kernel polynomials.
- **Lemma 3.** The degree-11 Taylor polynomial of `g` at the origin (exact rational coefficients) and its remainder constant `C₁₂ = 404.07` on the box `|t| ≤ 3/10`, `|χ| ≤ 1`.
- **Lemma 4.** The tensor 4-point Gauss–Legendre remainder on a cell, with the derivatives of `ρ` bounded through Bell polynomials.
- **Lemma 5.** The `v`-tail: `{v ≥ v₁} ⊂ {|t| ≥ T₁} ∪ {|χ| ≥ X₁}` with explicit `T₁`, `X₁`.
- **Lemma 6.** Closed-form bounds for the `τ`-tail, the `ω`-tails and the region `τ ≤ e^{−6.2}`.
- **The certificate (§3)** (computer-assisted). 2393 adaptive cells of `(u, ω) ∈ [−6.2, 18.6] × [ω_lo, ω_hi]`, the tensor 4-point Gauss rule on each, every node value `ρH` from a rigorous one-dimensional `v`-quadrature in Taylor-model arithmetic (30-digit outward-rounded decimal intervals), 38,288 nodes in twelve shards; the Lemma 4 remainders sum to at most `6.995·10⁻⁴`; control C10 bounds what the quadrature omits at the sliver cells (`[−3.4·10⁻³¹, 4.9·10⁻⁶²]` in `D`).
- **Theorem DD.** `0.0757052 ≤ D ≤ 0.0778601` (the certified enclosure is `[0.0757052049785748938, 0.0778600952308480156]`, width `2.155·10⁻³`), at #244 Theorem A's conditional scope.
- **Corollary DD1.** With note CJ's `J` and note DC's `−Ĩ_quad`, `q = J/30 − Ĩ_quad − D ∈ [0.672471, 0.674627]`, and by note V24's Theorem V, for every real `L ≥ 10`: `d = 3`: `0.0772809 ≤ (c₃ − R_{2/3})(L) ≤ 0.0776432` (`[0.0773381, 0.0775860]` for `L ≥ 24`); `d = 2`: `0.0614650 ≤ (c₃ − R_{2/3})(L) ≤ 0.0616635` (`[0.0614658, 0.0616628]` for `L ≥ 24`). ## Replay

    python3 -B -S frontiers/lifetime_dd_model_d_20261013/replay.py
    python3 -B -O -S frontiers/lifetime_dd_model_d_20261013/replay.py

`replay.py` uses the standard library only. A full run takes about 20 minutes per mode, almost all of it in `dd_exact.py`'s recomputation checks; `--quick` skips the assembly replay and the node-mutation control (about two minutes). It runs five checks:
1. **Identities.** Every stored file has the identity pinned in `SOURCES.json`, the tree holds nothing else, and there are no symlinks.
2. **The pin.** Every certificate file named in the table of the stored controls comment (23 files) and in the table of the stored controls addendum (3 files: C10 and its stdout in both modes) has the byte count and SHA-256 the comment states.
3. **The replays**, each under the current interpreter's `-O`/`-S` flags, with stdout byte-identical to the stored record and empty stderr: `dd_controls.py` (controls C1–C9, exit 0 iff all pass), `dd_mutants.py` (nine mutants, each rejected), `dd_gapcheck.py` on the stored cells (control C10) and `dd_exact.py` on the stored cells and node files (the tiling and disjointness checks, every cell remainder recomputed, 24 sampled node values recomputed, `D` and the corollary).
4. **Negative controls.** A one-byte change to the stored note (`DD/PROOF.md`) is detected; one changed digit in one stored node value changes the assembled result (the assembly is run on a temporary copy without the recomputation checks, and its stdout must differ from the record); `dd_exact.py` with one node file missing exits 1 (`incomplete node values`).
5. **Named identities.** Each stored verdict, summons and author record names the byte counts and SHA-256 of the stored bodies it refers to: the slice verdicts name v1.0 and the controls comment; the readback summons, the readback verdict, the first read-complete note and the engineering read name v1.0 and v1.1; the C10 summons and verdict name v1.1, v1.2 and the controls addendum; the second read-complete note names all of them (`SOURCES.json`, `names_identities`).

On a child time-out, `replay.py` keeps the partial streams and a `timeout` record in the evidence directory before failing (a point of the Codex review). The mutant driver `dd_mutants.py` runs its mutated copies of `dd_controls.py` under `-B -S` in both workflow modes; this is by design of the pinned certificate (the controls use `require`, not `assert`, so they are mode-independent, which the controls replay verifies in both modes) and is recorded here as a known limitation of the mutant lane (the Codex review's second point).

The workflow `.github/workflows/lifetime-dd-model-d.yml` runs on Python 3.11.16, in two jobs, one per mode, each with a 120-minute limit. Each job runs the protocol and raw-evidence tests (`tests/test_lifetime_dd_replay_protocol.py`, 15 tests; `tests/test_lifetime_dd_replay_evidence.py`, 9 tests), then the full replay, and retains the raw child streams as an artifact. These finite controls check explicit enclosures and identities, as the reads say. They do not prove the analytic statements.
