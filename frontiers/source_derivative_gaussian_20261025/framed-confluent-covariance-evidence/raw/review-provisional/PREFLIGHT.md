## 2. Finite contact rank, ordinary XY and both orientations: PASS

The actual accepted lower-jet API is
`I4SourceRemoteJetWitness.jet2`, `localGerm`, `localGerm_jet2` and
`jet2_mul`. The literal lower order is

`localGerm_jet2 c hc z j s` states the exact Kronecker basis identity
for all six entries. The public declaration index does **not** export

write a future precode contract as if those were accepted public names.
Small finite-linearity adapters using ordinary derivative linearity are
new private obligations; they fit this leaf.

Write `e=(a,b)`, `n=(c,d)` and `Delta=ad-bc`, so `Delta=+1` or `-1`.
The exact six-row coordinate change from ordinary Cartesian lower jets to
`(f,f_e,f_n,f_ee,f_en,f_nn)` is

    f;
    a f_x+b f_y;
    c f_x+d f_y;
    a^2 f_xx+2ab f_xy+b^2 f_yy;
    ac f_xx+(ad+bc)f_xy+bd f_yy;
    c^2 f_xx+2cd f_xy+d^2 f_yy.

Its gradient block has determinant `Delta`, its symmetric-Hessian block
has determinant `Delta^3`, and its full determinant is `Delta^4=1`.
Equivalently invert it by `grad f=e f_e+n f_n` and

    Hess f = f_ee e e^T + f_en(e n^T+n e^T) + f_nn n n^T.

Thus the route works for both frame orientations. The coefficients `2ab`,
`ad+bc`, `2cd` are essential to the ordinary-XY convention. This is finite
jet-coordinate algebra, not a source-law rotation.

converting the accepted generic `localGerm alpha ...` functions to the
original source. An arbitrary unrelated nonzero `c` in the germ theorem

derivative of the cube at its zero is `6 e_j^3`. Signed `alpha` causes
