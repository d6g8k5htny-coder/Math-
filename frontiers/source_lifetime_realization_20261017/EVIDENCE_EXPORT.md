# Exact public evidence projection

The final evidence exporter preserves the full selected UTF-8 receipt, log, review, fixture and verification-program text. It replaces only three explicitly enumerated local filesystem prefixes, longest prefix first, with `@C291_ROOT@`, `@PINNED_LEAN_RUNTIME@`, and `@PINNED_DEPENDENCY_CACHE@`. Relative suffixes, process identifiers, execution times, resource limits, environment import paths, outcomes, diagnostics, multiline axiom lists, private/generated declaration names and actual agent attribution remain intact. It does not select individual receipt fields or reserialize receipt JSON.

`PUBLIC_EVIDENCE_PROJECTION.json` names every exported file, its original and exported SHA-256 values and byte lengths, its evidence role, and each prefix replacement count. The public mapping lists logical labels; the corresponding private mapping retains exact machine prefixes. Original and projected hashes are deliberately distinct when text changed. A file requiring no projection retains its exact original bytes. Known private storage identifiers, storage URLs and unmatched machine paths cause the export to fail. Full output is rejected rather than silently dropped when a check cannot be satisfied.

`prepare_public_evidence_inputs.py` selects the complete final nineteen-module build and five named-module standard kernel-replay receipt/start/stdout/stderr quartets, plus both preserved final-sequence failures (26 execution quartets in all); the original failed sequence, audit-recovery sequence, terminal sequence and both recovery START records; all five actual negative-control/probe executions; exact fixtures, raw single-edit clones and their manifests; the original baseline's retained instrumentation failure and separately observed proof-binding probe; full final nonauthor review and its acceptance bindings; source inventories and the terminal dependency rehash summary; and the actual verification and projection scripts. The exporter requires terminal source-bound results before writing a new final directory and refuses to overwrite an existing projection.

Earlier development failures, explicitly stopped attempts and preparations remain in the immutable private handoff. The final audit timeout and first kernel child-discovery failure are also exported in full. The terminal result reuses every successful source build, permits only the documented unresolved retries, and does not replace either historical failed result. Public checkpoints and the final review describe their actual disposition. The original baseline's `control_pass: false` is preserved; the two-part acceptance does not rewrite it. The complete private dependency-artifact inventory and compiled objects remain private, while their byte hashes, dependency revisions and exact source identities are retained in the public evidence. The public verification scripts are reviewable execution/evidence source: the projected scripts and logical paths are not a standalone executable copy of the private-custody verifier. Reproducing the mathematical package uses the unchanged Lean sources and pinned Lake configuration described in the README.

The local source rebuild, standard kernel replay, declaration-wide transitive axiom census, semantic mutations, nonauthor review, hosted CI, public byte readback and private custody are separate observations. Existing hosted repository gates do not register or build this new standalone Lean package. No later hosted success can be inferred from the local transcript. An OpenAI subagent review is source-exposed same-provider work, not human or provider-distinct review.

After final evidence is added, the package's static checker verifies all nineteen source identities and configuration mappings, and its controls reject corrupted proof/identity/configuration/audit evidence and prohibited private paths. Exact disclosed agent identifiers are retained as provenance; a token followed by a filesystem path is still rejected. Earlier static checkpoint reports remain explicitly historical. No proof bytes, dependency pin, original target assumption, source owner or shared workflow changes as part of this projection.
