It is reviewer reconstruction, not an author-source edit or a new hypothesis.

Let S(x,f) be the local sector tests in §2, including criticality, the simple
negative Hessian with the specified hard eigenvalue, the unique Q5>0 frame,
the compact jet boxes, 0<r<r0 and the actual residual C7 cutoff. Do not include
a global Morse/distinct-height indicator in S. These tests make sense and are
Borel on all smooth fields; extend S by zero where their local denominators
or simple eigenframe are unavailable.

Define D_f(x) on all smooth fields as in §7: the supremum over rational c<f(x)
at which x connects in {f>c} to a point with value greater than f(x), with empty
supremum -infinity. Countable geodesic-ball chains and dense endpoint tests
make this Borel. For Borel B subset (0,infinity), use the everywhere Borel mark

    w_B(x,f)=S(x,f) 1{D_f(x) is finite}
                    1{f(x)-D_f(x) in B}.

The original field F is Morse with distinct critical values almost surely.
On this event the sum of w_B over its critical points is exactly the actual
sector-bar count N_A4(B): classical elder H0 identifies D with the death,
and the deterministic local enclosure proves that every marked birth has
an older point and hence is not essential. The count defined to be zero on
the original null complement therefore has the same expectation as this
extended critical-root sum. This is an equality of observables almost surely
under the ORIGINAL field law, not a claim of pointwise equality on every
conditional fiber.

Apply the one-point all-Borel Rice identity to w_B. Its canonical full-jet
kernel is f_z=omega+m(z). Since Hm(z)=0 and H omega=omega, its sector residual
cutoff is exactly 1{||omega||C7<=R}; the actual mark has not been replaced by an
independent auxiliary draw. At every target z_r in the sector, for EVERY
cutoff residual, §7 proves D_(f_zr)(x)=b-Delta(r,omega) by the boundary barrier
and outgoing ridge path. It follows directly that the conditional mark equals

    1{||omega||C7<=R} 1{Delta(r,omega) in B}

when the other displayed jet-sector tests are met. The coordinate changes then
give (25). No conditional global Morse indicator has been deleted. One was
never present in the Borel extension to which Rice was applied.

At the limiting target z0, the contact is forced degenerate; no global Morse
statement about that law is needed either. The coefficient limit concerns the
explicit finite jet density, deterministic local lifetime and fixed residual
cutoff, not an attempted exceptional-target extension of a genericity theorem.

The source explicitly supplies the everywhere intrinsic threshold (§7), the
original almost-sure actual-bar identification, and the all-Borel identity
(§3), and says that its conditional trapping/density argument does not assume
global Morse behavior. Thus this is a legitimate conventional inference from
its written constructions. A sentence spelling out w_B before (25) would aid
readers, but no required mathematical amendment or added hypothesis is needed.
The reviewed interpretation is precisely this one. Inserting a global Morse
indicator in the kernel and discarding it by unconditional genericity would
be invalid and is not accepted.
