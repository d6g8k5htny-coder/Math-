Classify every Git *blob path* ending in `/PROOF.md` under `frontiers/` at each cut. Match by **full path** and **full 40-hex blob**; an unchanged path with a changed blob is a changed source, not a retained proof. Missing Git objects in a shallow clone mean **not verified**, never a claim that the source did not exist. **Scope limits:** This is a complete *recursive `PROOF.md` delta* between two identified cuts, **not** a comprehensive theorem catalogue or semantic dependency index.
