# T-FIXED-REMOTE — Fixed-remote height-window count

**Author-side status:** closed theorem. **Community / `lemma_closed`:** not implied.

## Statement (Theorem A)

On `D_ρ = {dist ≥ ρ}` with between-pin height window, the weighted expected index-`j` count is asymptotic to a positive continuous contact kernel times `k r³`, with O(r) total-variation error; in particular `E N ≤ C k r³ |E|`.
