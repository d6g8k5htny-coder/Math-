# Research status

## Current standout

Canonical partition-trajectory possibility: possibility as the family of future task–loss structures that a causal information trajectory can keep actionable.

## Tested

- Exact causal refinement and infeasibility witnesses
- Static/dynamic memory-reuse separation
- Future-aware versus greedy retention
- Flexibility and multitask risk frontiers
- Genuine MI–risk divergence under a shared observation model
- Randomized minimax and realization-level attacks
- Independent asymmetric visibility curves and factorized gap
- Robust expected-loss regime
- Correlated-noise failure of the independent factorization

## Discarded or bounded

- Entropy as an approximate action-success measure
- Memory capacity as a sufficient capability metric
- Robust memory as the default optimum under uncertainty
- Task mutual information as a universal proxy for actionable capability
- Static filtration as the only information model
- Extendability as an independent predictive diagnostic
- Universal cohomological or factorized uncertainty claims

## Next optional moves

- Classify piecewise correlated-noise regions rather than extending the factorization heuristically
- Apply the solver to a larger finite planning benchmark
- Add SAT/SMT or dynamic-programming backends for larger state spaces
- Test asymmetric and correlated observation schedules under explicitly matched visibility and timing

The current package is self-contained and suitable for external execution and evaluation.
