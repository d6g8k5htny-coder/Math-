## 2. Three lemmas

**L1 (the primitives `J_k`).** Write `J_k(s) = A_k √(2π) erf(s/(2√2)) + B_k + C_k(s) e^{−s²/8}` with rational `A_k, B_k` and a
rational polynomial `C_k`, generated from `J_0 = √(2π) erf(s/(2√2))`, `J_1 = 4(1 − e^{−s²/8})` by the recurrence. The triple is
characterised by `J_k(0) = 0` (`B_k + C_k(0) = 0`), `J_k'(s) = s^k e^{−s²/8}` (`A_k + C_k'(s) − (s/4) C_k(s) = s^k` as polynomials),
and `J_k(∞) = ½ 8^{(k+1)/2} Γ((k+1)/2)`; all three are verified exactly for `k ≤ 7` (rule `JK_EXACT`). For odd `k`, `A_k = 0`.

**L2 (base integrals).** For `λ > 0`, `κ > 0`:

```
M_0(λ, 1) = ½ √(π/λ),      M_1(λ, 1) = 1/(2λ),      M_0(λ, erf(κ·)) = arctan(κ/√λ) / √(πλ).
```

*Proof of the third.* `∂_κ ∫_0^∞ e^{−λs²} erf(κs) ds = (2/√π) ∫_0^∞ s e^{−(λ+κ²)s²} ds = 1/(√π (λ + κ²))`, and the value at
`κ = 0` is `0`, so `M_0(λ, erf(κ·)) = (1/√π) ∫_0^κ dt/(λ + t²) = arctan(κ/√λ)/√(πλ)`. ∎
(The code also carries `∫_0^∞ e^{−λs²} erf(us) erf(vs) ds = arctan(uv/√(λ(λ+u²+v²)))/√(πλ)`, needed only if an even `k`
occurred; it is not on the path of `D_3`, and a float control checks it, rule `BASE_INTEGRALS_FLOAT`.)

**L3 (moments by parts).** For `n ≥ 1` and `f ∈ {1, erf(κ·)}`, writing `s^n e^{−λs²} f(s) = s^{n−1} f(s) · s e^{−λs²}` and
integrating by parts,

```
M_n(λ, f) = [ (n−1) M_{n−2}(λ, f) + (2κ/√π) M_{n−1}(λ + κ², 1) ]/(2λ)        (the second term only for f = erf(κ·)),
```

because `d/ds erf(κs) = (2κ/√π) e^{−κ²s²}` and the boundary term `[−s^{n−1} f(s) e^{−λs²}/(2λ)]_0^∞` vanishes for `n ≥ 2`
(`s^{n−1} = 0` at `0`) and for `n = 1, f = erf(κ·)` (`erf(0) = 0`); for `n = 1, f = 1` it equals `1/(2λ)`, which is the base value
`M_1(λ, 1)`. The recurrence terminates at `M_0` and `M_1` of L2. As an internal check, the recurrence at `f = 1` reproduces
`½ Γ((n+1)/2) λ^{−(n+1)/2}` exactly for `n ≤ 12` and every `λ` that occurs (rule `GAUSS_MOMENTS`).

By L1–L3, `D_3` is a finite `Q`-linear combination of `√r π^{k/2}` and `√r π^{k/2} arctan(θ)` with `θ = κ/√λ` for the two
`λ` of the erfc branch: `θ = κ√24 = 1` (`λ = 1/24`, `arctan 1 = π/4`) and `θ = κ√6 = 1/2` (`λ = 1/6`). Hence
`D_3 ∈ Q + Q·π^{−1} + Q·π^{−1} arctan(1/2)` after the powers of `√π` combine (they do; every surviving term is rational
times `π^0` or `π^{−1}`).

## 3. The exact computation

exact prefactor `1/(32π)` and `G_0` constant `√(2π/3)` (both produced from Mehta's `Z_3` and `α = 3/8` in the same
arithmetic). The result, with the two branches separately:
