# Scope of the statement-only Lean package

Scientific effect: **NONE**. Formal progress: `specified` for every declaration. Alignment:
`PENDING_INDEPENDENT_REVIEW`. Organizational-independence credit: 0 (Anthropic / Claude).

## Boundary

This package states; it does not prove. The five modules under `Specifications/` declare, as
`def … : Prop` and interface `structure`s in the namespaces `UniversalLaw.Spec.<Module>`, the
objects and results of the byte-pinned Layer 0 texts in `sources/`. Anything the informal text
leaves informal (a Kac–Rice representation, "versions of the densities", the elder pairing, the
exact weighted law, the field itself) is a *field* of an interface structure whose docstring names
the source clause, never an axiom, and the Prop is stated for every object satisfying the
interface. Every specification docstring carries `Source:` (repository, commit, path, sha256),
`Anchor:` (a verbatim quote of the pinned bytes), `Interface:` (which inputs are given objects
whose defining property is a hypothesis field) and `Does not claim:`.

The source scan (`check.py`, no Lean) refuses, in every module, as whole tokens of
comment-stripped code: `theorem`, `lemma`, `example`, `instance`, `axiom`, `sorry`, `admit`,
`native_decide`, `unsafe`, `opaque`, `partial`, `macro`, `notation`, `syntax`, `elab`,
`set_option`, `run_cmd`, `implemented_by`, `extern`, `decreasing_by`, `deriving`, `attribute`,
`include`, `omit`, `mutual`, `inductive`, `class`, `local`, `scoped`, `export`, `alias`,
`irreducible_def`, `Sort`, `_root_` and the rest of its list; string literals, guillemet names,
`#` commands and attributes anywhere in code; any command keyword off column 0 (so `open … in`,
two commands on one line and indented commands); any column-0 command other than `import`,
`namespace`, `end`, `open`, `def`, `noncomputable def`, `abbrev`, `structure` (`section` and
`variable`, which DESIGN 3b lists, are refused until a module needs them: a `variable (h : False)`
mentioned in a body would add a vacuating hypothesis the scan cannot see); imports other than
`Mathlib`; a definition without an explicit result
type; a Prop-valued result type not written exactly as `: Prop`; a proof-shaped result type (a
depth-zero relation, `True` or `False`); a declaration name with a `_`-prefixed component; a
registered-kind declaration without the four labelled docstring lines; a docstring or register
anchor shorter than 16 characters (a one-character anchor is verbatim in any source); a root module importing
anything but the five registered modules in order; unfilled double-angle-bracket table placeholders in README.md or SCOPE.md.
The scan is a fail-closed pre-Lean stage and not a Lean lexer.

The authority is the environment audit of `check.py --execute` (`.lake/evidence/Environment.lean`):
Lean's own `ConstantInfo` of every constant the five modules add is classified as `structure`,
`statement` (type syntactically `Prop` or `∀ …, Prop`, read through `forallTelescope` without
reduction: a `Set`-valued definition, whose type unfolds to `… → Prop`, is `auxiliary` exactly as
the scan's `: Prop` rule has it, while the reducing `isProp` still decides "proof"), `auxiliary`
(any other definition) or `generated`
(projections, recursors, `casesOn`, `noConfusion`, `injEq`/`inj`/`sizeOf_spec`, `_sizeOf_*`,
`match_*`, `_proof_*`: tolerated only when range-less, flagged by the environment or an internal
name under its structure, and still axiom-checked); every other theorem, axiom, opaque or
quotient constant, non-structure inductive, instance, or definition whose type is a proposition
is refused, as is any transitive axiom outside `propext`, `Classical.choice`, `Quot.sound` for
any constant. The audit's `statement`, `structure` and `auxiliary` sets must equal the register
and the scan exactly. The build log is refused on `declaration uses` and on Lean's "is a
proposition; use `theorem`" linter. The lakefile pins `autoImplicit = false`, so an unbound name
in a header is an error rather than a silent implicit parameter. The audit is itself controlled
in every `--execute` run: an honest control file must classify exactly, and a control file hiding
a theorem between string literals, an indented Prop definition, a proof written as `def`, a
`sorry`, an `axiom` and an `instance` must be refused for exactly those reasons.
